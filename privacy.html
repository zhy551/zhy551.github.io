ar-rclone privacy policy

ar-rclone is used only by its owner, on the owner's own computer, to access the owner's own Google Drive through rclone.

  • Google user data accessed: the files and file metadata in the owner's Google Drive.
  • Use: copying files between the owner's computer and the owner's Drive.
  • Storage: the OAuth token is stored only in a local configuration file on the owner's computer.
  • Sharing: no Google user data is collected by, or sent to, any server operated for this app, and none is shared with third parties.
  • Revoking access: remove ar-rclone at Google Account permissions.
